# PRINTF_QUEST

🇪🇸 **Español** · [🇬🇧 English below](#english)

Minijuego retro (monitor ámbar) para aprender y repasar **ft_printf** de 42, desde cero hasta el bonus. Es un único `index.html`, sin dependencias salvo las fuentes de Google.

## Modos
- **Quest:** 6 sectores (FORMATO, VARIÁDICAS, CONVERSIONES, BASES, LÍMITES, BONUS), 58 preguntas de ★ a ★★★★. Tres vidas por intento, XP y 5 rangos.
- **Survival:** construye las 9 funciones (de `ft_putchar` a `conv_int`) ordenando piezas de código. Una vida: un fallo y empiezas de cero.

## Tipos de reto
Elegir, marcar varias, completar código, encontrar la línea con el bug, ordenar piezas (con líneas trampa) y un **simulador paso a paso** que recorre un formato como `%-5d|%.3s`, te pregunta qué tipo lee `va_arg`, qué escribe cada conversión y cuántos bytes devuelve `ft_printf`.

## Extras
ES/EN, música chiptune, efectos de sonido, progreso guardado en el navegador (y en la cuenta cuando se abre desde claude.ai).

Hecho por coscosgram.

# PRINTF_QUEST (English)

A retro amber-monitor minigame to learn and review 42's **ft_printf**, from zero to the bonus. A single `index.html`, no dependencies apart from Google Fonts.

## Modes
- **Quest:** 6 sectors (FORMAT, VARIADICS, CONVERSIONS, BASES, LIMITS, BONUS), 58 questions from ★ to ★★★★. Three lives per attempt, XP and 5 ranks.
- **Survival:** build the 9 functions (from `ft_putchar` to `conv_int`) by ordering code pieces. One life: a single mistake and you start over.

## Challenge types
Single choice, multi-select, fill-in code, spot the buggy line, order code pieces (with trap lines) and a **step-by-step simulator** that walks through a format like `%-5d|%.3s`, asking which type `va_arg` reads, what each conversion writes and how many bytes `ft_printf` returns.

## Extras
ES/EN, chiptune music, sound effects, progress saved in the browser (and in your account when opened from claude.ai).

Made by coscosgram.
